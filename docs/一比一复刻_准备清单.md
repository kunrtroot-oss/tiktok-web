## 一、你的三个问题（已解答，拍板结果见第三节）

### Q1：别人的包 500M，要求一比一，为什么我们的包没有那么大？

**一句话：那 500MB 不是"效果"，是"塞了两个别人家的安装包"。**

参考包体积的构成（我实际解包量的）：

| 内容 | 大小 | 是什么 |
|---|---|---|
| 内嵌第三方 APK | **269.80MB** | 他把别人的整包原封不动塞进自己包里，运行时再释放安装 |
| dex（代码） | 67.82MB | 它自己是完整的抖音客户端改用，不是网页壳 |
| .so（原生库） | 67.40MB | 视频编解码、图像处理等 |
| resources.arsc（资源表） | 77.67MB | 一堆语言/皮肤的字符串表 |
| res（图片等） | 12.75MB | |
| assets（网页资源） | 2.73MB | 真正跟"商城网页"有关的部分 |
| **我们的包** | **2.8MB** | 纯网页壳，没塞任何别人的东西 |

**所以"1:1"要看比什么：**

- 比**页面效果**（入口长什么样、点了去哪、页面怎么显示）→ 我们能做到 1:1，已经在做
- 比**字节数** → 做不到，也不该做。唯一让包变 500MB 的办法就是"把别人的 APK 塞进我们的包"，
  那是**侵权**，而且你现在遇到的病毒误报（`a.grav.BulimiaTGen.f`）**正是这种塞包行为最容易触发的特征**。
  也就是说：包做到 500MB，误报只会更严重，不会更轻。

**合法能做到多大？** 靠"内置自己的商城网页资源 + 图片素材"，自然能到 10–120MB。
如果你只是觉得"包太小看着不像正经 APP"，那走 M 档（30–120MB）就够了，我下面说怎么做到。

### Q3：`data=` 应该放什么？

**`data=` 是什么**：App 打开商城页时，会在网址后面挂一串编码信息，
告诉网页"现在是谁在用、什么平台、什么语言、要开哪个页面"。

**我们目前放的**（字段名是照抄参考包的，为了两端解析逻辑一致）：

| 字段 | 现在放的值 | 该不该留 | 说明 |
|---|---|---|---|
| `route` | `orderList` / `goodsList` / `shopCenter` | ✅ **必须有** | 网页靠它决定渲染哪个页面，删了页面就打不开 |
| `lang` | 系统语言，如 `zh` | ✅ 留 | 网页多语言用 |
| `timezone` | 系统时区，如 `Asia/Shanghai` | ✅ 留 | 网页显示时间/活动时间用 |
| `versonDate` | App 版本号 | ✅ 留 | 注意：**参考包这里就是拼错的 `versonDate`**，我们照抄以保持兼容，别自行改成 `versionDate` |
| `tkplatform` | `android` / `ios` | ⚠️ 参考包**没有**这个字段 | 是我们额外加的，方便网页区分两端。如果网页不认识它，留着无害 |
| `customID` | **空** | ❓ 待定 | 用户唯一标识（参考包给的是 `@用户名`） |
| `nickname` | **空** | ❓ 待定 | 昵称（参考包给的是 `hello`） |
| `avatar` | **空** | ❓ 待定 | 头像地址 |
| `tiktok_id` | **空** | ❓ 待定 | TikTok 用户 ID |

**关键要说的三件事：**

**① 那四个空字段为什么是空的，怎么补上**
参考包能拿到用户身份，是因为**它本身就是抖音客户端**（它改了官方登录回调，登录后自动写入）。
我们是个网页壳，没有抖音的登录 SDK —— 但**有更好的办法**：
我们的主页本身就在 WebView 里加载 `tiktok.com`，用户登录后，
**用户的昵称/头像/ID 就在这个已登录的网页里**，我可以注入一段脚本把它读出来，再传给商城页。
技术上能做，**但要你确认网页端是否真的需要这几个字段**——如果商城的"我的"页压根不显示用户信息，那就不用做。

**② 需要网页端给一份"字段对照表"**
现在是我按参考包猜的字段名。**只要有一个字母对不上，商城页面上就取不到值。**
请让写 H5 的人回一句：`data=` 是不是这个参数名？是不是 `base64` 解码？里面读哪几个 key？

**③ 安全提醒（重要）**
现在的 `base64` **只是编码，不是加密**——抓包能看到明文。
所以 `data=` 里**绝不能放登录 token、密码、手机号、金额类信息**。
如果以后要传敏感信息，必须换成真正的加密，不要沿用 base64。
